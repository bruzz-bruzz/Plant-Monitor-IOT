# Backend API

This is the backend for the plant monitoring system, built with Node.js, Express, and TypeScript. It acts as an intermediary between the ESP32 (data source) and the Frontend (data consumer).

## Setup
1.  Install dependencies: `npm install`
2.  Set up environment variables in `.env` based on `.env.example` (or provided `.env` file).
3.  Run the server: `npm run dev`

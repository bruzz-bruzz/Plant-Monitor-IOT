# Bill of Materials (BOM) - ESP32 Plant Monitoring System

| Item | Component / Module | Quantity | Description / Purpose |
| :--- | :--- | :---: | :--- |
| 1 | **ESP32 NodeMCU Development Board** | 1 | Microcontroller with Wi-Fi and Bluetooth for processing and cloud uploading. |
| 2 | **DHT22 (AM2302) Sensor** | 1 | Measures ambient air temperature and relative humidity. |
| 3 | **DS18B20 Waterproof Temperature Sensor** | 1 | Measures water or soil temperature (OneWire protocol). |
| 4 | **BH1750 Digital Light Intensity Sensor** | 1 | Measures ambient light levels in lux via I2C. |
| 5 | **Capacitive Soil Moisture Sensor (v1.2)** | 1 | Measures soil moisture percentage without rapid corrosion. |
| 6 | **TDS Sensor Meter Module** | 1 | Measures Total Dissolved Solids (water purity/nutrients) in PPM. |
| 7 | **Resistor 4.7k Ohms** | 1 | Pull-up resistor required for the DS18B20 data line. |
| 8 | **Breadboard and Jumper Wires** | As needed | For prototyping and connecting all sensors to the ESP32 pins safely. |
| 9 | **USB Data Cable (Micro-USB / Type-C)** | 1 | For powering the ESP32 and flashing code from the Arduino IDE. |
